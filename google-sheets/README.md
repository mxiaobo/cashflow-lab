# 现金流跟踪表 · Google Sheets 版

## 使用步骤

### 1. 准备 Google Sheet

1. 打开 https://sheets.new 新建一个空白表格
2. 给它起个名字，例如「现金流跟踪表」

### 2. 粘贴代码

1. 顶部菜单：**扩展程序 → Apps Script**
2. 在打开的 Apps Script 编辑器里：
   - **左侧**默认有 `代码.gs`（或 `Code.gs`）—— 把 `Code.gs` 的全部内容粘进去（覆盖原有的 `myFunction`）
   - 点击左侧 **文件 → +** → **HTML**，命名为 `Sidebar`（**不要带 `.html` 后缀，Apps Script 会自动加**）—— 把 `Sidebar.html` 的全部内容粘进去
3. **Ctrl/Cmd + S** 保存两个文件

### 3. 初始化

1. 关闭 Apps Script 编辑器，回到 Google Sheet
2. **刷新页面**（这一步必须做，否则菜单不会出现）
3. 顶部菜单栏会出现 **📊 现金流** 菜单
4. 点击 **📊 现金流 → 初始化 / 重置表格**
5. 第一次运行会弹出授权对话框，按提示授权

### 4. 开始使用

- **新增记录**：菜单 → 📊 现金流 → 新增记录（侧边栏录入）
- **查看仪表盘**：切到「仪表盘」标签
- **修改类别**：切到「类别」标签，直接改
- **填本金**：切到「本金」标签，填入每个收入来源的本金，自动算年化
- **改设置**：切到「设置」标签，修改年份等

## 创建的 Sheet 结构

| Sheet | 作用 |
|---|---|
| 仪表盘 | KPI + 3 个图表（趋势/饼图/堆叠柱）|
| 录入 | 原始记录（日期/月份/类别/金额/备注），按月份排序 |
| 类别 | 类别清单（可增删改）|
| 本金 | 各类别的本金，自动算年化 |
| 月度汇总 | 12 个月 × 类别 的交叉表（全公式）|
| 设置 | 年份、纪律红线等 |

## 设计亮点

- **数据只录一次**：所有汇总和图表都从「录入」表通过 SUMIFS 自动算
- **零值显示横线**：所有数字用 `"$"#,##0;[Red]"-$"#,##0;"—"` 格式
- **样式克制**：橙色仅 1 处（提交按钮），绿色仅用于合计/正向数字
- **网格线隐藏**：仪表盘 Sheet 不显示网格，更接近"卡片"感觉
- **侧边栏录入**：免去手动滚动到表尾，避免误改公式

## 自定义建议

- 改主题色：编辑 `Code.gs` 顶部的 `THEME` 对象
- 改默认类别：编辑 `DEFAULT_CATEGORIES`
- 改纪律：编辑 `DEFAULT_RULES`
- 改图表颜色：编辑 `buildCharts` 里的 `colors` 数组
